# College Social Network Platform

## Overview
College Social Network Platform is a web-based application designed to provide a digital interaction space for college students. The platform allows users to create profiles, share posts, interact through comments and likes, and manage user-generated content.

## Features
- User registration and authentication
- Create and manage user profiles
- Create, view, and manage posts
- Like and comment functionality
- User interaction management
- Structured storage of user and content data

## Tech Stack
- Frontend: HTML5, CSS3, Bootstrap 5
- Backend: PHP
- Database: MySQL
- Tools: VS Code, XAMPP/WAMP, phpMyAdmin

## Database Design
The application uses a relational MySQL database to manage:
- User information
- Posts and content
- Comments
- User interactions
